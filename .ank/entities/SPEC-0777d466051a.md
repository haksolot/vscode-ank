`src/ank/` is the only part of this extension that knows a subprocess exists.
Everything above it receives typed values or a typed error.

## Invocation

1. One function spawns, and it uses `execFile` with an argument array. No shell
   is involved anywhere, so no argument is ever escaped or quoted by us.
2. `--json` and `--repo <folder>` are appended by the adapter, not by callers.
   A caller that could forget `--repo` is a caller that can address the wrong
   corpus, silently.
3. `--worktree` is passed when the corpus is anchored to a tree elsewhere.
4. `ANK_AGENT` is set once per window, defaulting to `vscode/<version>@<host>`
   and overridable by the `ank.agent` setting. Two windows on one tree with no
   distinct identities are **one agent** to the refs: they share a claim
   instead of arbitrating over it, and the second is quietly refused work it
   should have been given.

## Result

    { code: 0, value: T }                    exit 0, stdout parsed
    { code: 1..9, error: AnkError }          stdout empty, stderr parsed

`AnkError` carries `code`, `message` and `hint | null`, parsed from
`error[N]: message` and the following `  -> hint` line. The hint is offered to
the user as a suggested next command; it is never matched on.

Exit 8 from `check` and `review` is **not** an error. It is a successful answer
that carries findings, and it arrives with stdout populated.

## Types

One interface per document shape, derived from the `returns` list of
`ank help --json`. Three verbs answer two questions and get two interfaces
discriminated at the call site, not at runtime:

    show    over a task | over an ADR, a spec or a log entry
    log     reading | appending
    config  reading | writing

Nullable fields are `T | null`. Unknown fields are ignored, never rejected.

## Capability probe

`ank help --json` runs once at activation. It is generated from the same table
the binary dispatches from, so it cannot fall behind the binary. What it
answers:

- whether `ank` is on the PATH at all, and at what version;
- which verbs exist, so a command contributed against a verb an older binary
  lacks is disabled rather than failing when clicked;
- the `summary` of each verb, reused verbatim as the description of the
  matching language model tool.

A binary that is absent is exit 9 territory: an environment to repair, reported
once with the install line, never as a broken corpus.
